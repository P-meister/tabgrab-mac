# Tabgrab for Mac

Downloads of the Tabgrab Mac app. Get it from [tabgrab.dev/download](https://www.tabgrab.dev/download).

The newest version is always at
https://github.com/P-meister/tabgrab-mac/releases/latest/download/Tabgrab.dmg

Needs a Mac with Apple silicon (M1 or later). The app is not yet notarized by Apple, so the first time you open it,
macOS asks you to confirm in System Settings > Privacy & Security.
